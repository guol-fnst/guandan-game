# 掼蛋策略资料与实现决策

检索日期：2026-11-14。实战意见与实验论文均不构成最优策略证明。本项目规则以现有引擎为准。

## 阅读与取舍

- [程冠东《掼蛋实战十三“牌”》](https://gxguandan.cn/industry/30.html)：署名实战经验，强调组牌灵活性、搭档配合和用炸时机。采用整体规划思路；不把文章中按余牌张数判断的经验转成必炸、必让的硬条件。
- [Yim 等，Guandan 中的 LLM 与 Theory of Mind，2024](https://arxiv.org/html/2408.02559v1)：论文讨论候选推荐、公开历史下的行为推断、规划评价，以及长动作列表的处理困难。采用“候选+可读状态+行为假设+后续方案比较”；不声称复现其训练推荐器或论文效果，不增加多轮模型调用。
- [DanZero+，2023](https://arxiv.org/abs/2312.02561)：使用强化学习处理复杂合作竞争和动作空间。这里只借鉴评估意识，未安装或接入其模型，提示词不能代替训练策略。
- [OpenGuanDan，2026](https://arxiv.org/abs/2602.00676)：包含代理对抗、人机对抗与独立玩家接口。借鉴多种对手、换位配对和独立信息边界的评估方向；不是本项目已完成的外部基准认证。

## 我们的实现选择（综合上述资料后的工程判断）

每手统一比较：团队名次 → 领牌/回手路线 → 控制资源 → 余牌结构 → 座次拦截 → 对手危险应对。
STRATEGY_GUIDE 与 strategyBrief 在 server/src/engine/aiStrategy.ts，是运行时使用的指南和局面摘要；本文件记录依据，运行时不联网抓文章。

自然级牌、逢人配分别记录。自然级牌可形成的对子和三张相互重叠，不能当成独立控制次数；所有级牌信息由 currentLevel 计算。普通牌组合也可能消耗宝贵的控制资源。

沿用合法性校验、候选多样性、团队保护和有限模拟；不把文章口诀直接加入最终否决条件。不取消已有安全检查，不假设所有规则已统一为最优价值函数。

## 验证边界

检查不同级牌的摘要、自然级牌与配牌区分、模型请求确实携带指南，以及现有策略回归。
后续提升强度需用相同发牌、换位、多种对手做重复对照；局部案例与单局胜负都不能证明总体提升。
